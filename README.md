# Rank-Path GitHub Pages Website

เว็บไซต์ Static HTML พร้อมใช้กับ GitHub Pages

## Files
- `index.html` — หน้าเว็บไซต์หลัก
- `style.css` — Responsive styling
- `script.js` — Mobile menu + copyright year
- `assets/` — Logo และภาพประกอบเว็บไซต์

## Deploy to GitHub Pages
1. สร้าง GitHub repository ใหม่ เช่น `rankpath`
2. Upload ทุกไฟล์และโฟลเดอร์ใน ZIP นี้ไว้ที่ **repository root**
3. ไปที่ **Settings → Pages**
4. ใน **Build and deployment** เลือก **Deploy from a branch**
5. Branch เลือก `main`
6. Folder เลือก `/(root)`
7. กด **Save**

GitHub จะสร้าง URL เว็บไซต์ให้หลังจาก deploy เสร็จ
